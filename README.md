# Employee Management System

A Production-Ready Employee Management Platform built for DevOps learning.

## Tech Stack
- **Application**: Spring Boot (Java 21)
- **Database**: PostgreSQL
- **Containerization**: Docker
- **Registry**: AWS ECR
- **CI/CD**: GitHub Actions
- **Cloud**: AWS EC2
- **Monitoring**: CloudWatch
- **Web Server**: Nginx
- **Deployment**: Blue-Green

## Project Phases
- Phase 1: Project Setup & Git Strategy
- Phase 2: Spring Boot Application
- Phase 3: PostgreSQL Integration
- Phase 4: Database Migrations (Flyway)
- Phase 5: Unit Testing
- Phase 6: Dockerization
- Phase 7: Docker Compose
- Phase 8: GitHub Actions CI
- Phase 9-12: AWS Setup & Secrets
- Phase 13-15: Multi-Environment Deployment
- Phase 16: Blue-Green Deployment
- Phase 17-20: Monitoring, Backup & Rollback
